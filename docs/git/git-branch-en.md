# Git Branch and Merge

## 1. Update the main branch

#### 1.1. Switch to the main branch
```
git checkout main
```

#### 1.2. Pull the latest changes from the repository
```
git pull origin main
```

---

## 2. Create and switch to the new branch

#### 2.1. Create a new branch
```
git branch new-branch-name
```

#### 2.2 Switch to the new branch
```
git switch new-branch-name
```

#### Extra. This command creates and switches to the new branch all at once
```
git switch -c new-branch-name
```

---

## 3. Make changes and commit

#### 3.1 Add changed files
```
git add .
```

#### 3.2 Commit with a message
```
git commit -m "Update main.c"
```

---

## 4. Push the new branch to GitHub
```
git push -u origin new-branch-name
```
*Note: The next times you want to push changes to this same branch, just type `git push`.*

---

## 5. Create a Pull Request and Merge

#### 5.1. Create a Pull Request on GitHub
In the Pull Request title you should describe what was done within this branch. If you want you can add a description, but it is optional.

#### 5.2. Merge on GitHub
*Important: When merging you should not change its title, you should keep the title generated by GitHub, looking something like this:*
```
Merge pull request #1 from ricanudo/create-database
```

---

## 6. Cleanup

#### 6.1. Switch back to the main branch
```
git checkout main
```

#### 6.2. Pull the updated repository version from GitHub
```
git pull origin main
```

#### 6.3. Delete the branch from GitHub via terminal
```
git push origin --delete new-branch-name
```

#### 6.4. Delete the local branch
```
git branch -D new-branch-name
```

#### 6.5. Clean branch history
```
git fetch -p
```
